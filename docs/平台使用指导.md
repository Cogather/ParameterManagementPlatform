# 参数管理平台使用指导

> **适用对象**：产品配置人员、参数维护人员、测试与实施人员。  
> **截图说明**：文中以 **【截图：……】** 标记插图位置，交付时请替换为实际界面截图。

---

## 第一章 简介

### 1.1 平台简介

**参数管理平台**用于集中管理设备软件 **OM 系统参数**。您可以在选定某一产品后，依次完成：产品形态维护 → 命令与参数类型配置 → 各类基础字典配置 → 按版本维护具体参数，并支持批量导入导出、参数基线锁定与操作记录查询。

平台可单独打开使用，也可嵌入公司其它管理系统；嵌入时顶部仍保留「模块切换 + 产品选择」，便于在同一界面内完成全部配置工作。

### 1.2 主要功能

| 模块 | 您能做什么 |
|------|------------|
| **产品配置** | 为当前产品维护多种**产品形态**（如不同软件形态），并设置参数类型、责任人。 |
| **命令管理** | 维护**命令**、命令下的**参数类型与序号范围**、各**版本**可用的序号区段。 |
| **配置管理** | 维护版本、业务分类、变更来源关键字、适用网元、NF、生效方式/形态、项目组、版本特性等**基础选项**，供录入参数时选用。 |
| **参数管理** | 在指定**产品 + 版本**下新增、修改、导入、导出参数，执行**基线/解锁**，按命令与类型筛选查看。 |
| **批量导入导出** | 多数列表页支持 Excel（`.xlsx`）模板批量维护；导入时逐行处理，已成功行不会因后续行失败而撤销。 |
| **操作日志** | 在多数配置页查看本产品的历史增删改记录。 |

> **说明**：工具栏中的「参数同步」当前为预留功能，按钮呈灰色不可用。

### 1.3 如何找到各功能

顶栏从左到右四个模块（默认进入 **产品配置**）：

1. **产品配置**
2. **命令管理** — 内含页签：**命令** | **类型定义** | **版本区段**
3. **配置管理** — 内含页签：**产品版本** | **业务分类** | **变更来源关键字** | **适用网元** | **NF 配置** | **生效方式** | **生效形态** | **项目组** | **版本特性**
4. **参数管理**

顶栏右侧为 **「产品：」** 下拉框。除「产品配置」外，其它模块都需要**先选好产品**才能操作；未选产品时，列表为空或按钮变灰，并提示「请先选择产品」。

【截图：顶栏模块切换与产品选择器】

### 1.4 建议使用顺序

1. 在顶栏 **选择要维护的产品**。
2. 打开 **产品配置**，补充或调整该产品下的 **产品形态**（若尚未配置）。
3. 进入 **命令管理**，配置命令、类型与版本区段。
4. 进入 **配置管理**，至少维护 **产品版本** 及其它表单会用到的字典项。
5. 进入 **参数管理**，选择版本后维护具体参数。

**注意**：切换顶栏产品时，参数页等处的 **版本选择会被清空**，需要重新选择版本，以免看错数据。

## 第二章 分模块使用指导

### 2.0 顶栏：选产品与切换模块

#### 页面简介

顶栏用于在四大模块之间切换，并指定当前正在维护的**产品**。本身不展示业务表格。

#### 使用指导

1. 点击 **产品配置 / 命令管理 / 配置管理 / 参数管理** 进入对应功能。
2. 在 **「产品：」** 下拉中搜索并选择产品；切换后，各页面数据自动按新产品刷新。
3. 从其它系统带产品、版本信息跳转进入时，平台会自动带入对应选项（若您通过统一门户访问，一般无需手工处理）。

【截图：切换产品后各模块提示变化】

#### 注意事项

- **所有配置数据都归属某一产品**，不能跨产品混用。
- **切换产品后，请重新选择版本**（参数管理、版本特性等页面）。

### 2.1 产品配置

**进入方式**：顶栏 → **产品配置**

#### 页面简介

用于维护**当前已选产品**下的 **产品形态** 列表。每一行包含：**产品形态名称**、**参数类型**（Single 或 Multi）、**责任人**。

本页**不能新建产品**——产品只能在顶栏「产品：」中选择；本页只管理该产品下有哪些形态。

#### 使用指导

1. **先在顶栏选择产品**；未选时会提示：「请先在上方选择产品，再配置该产品下的产品形态」。
2. 表格列出当前产品下所有有效形态，底部分页可翻页。
3. 需要追溯变更时，点击右上角 **「操作日志」**。

【截图：未选产品时的空状态】  
【截图：已选产品后的形态列表】

#### 功能操作

| 功能 | 操作步骤 | 截图位置 |
|------|----------|----------|
| **新增产品形态** | 点击「新增产品形态」→ 填写形态名称、参数类型、责任人 →「确定」。 | 【截图：新增产品形态弹窗】 |
| **编辑** | 点击该行「编辑」→ 在行内修改 →「保存」或「取消」。同一时间只能编辑一行。 | 【截图：行内编辑态】 |
| **删除** | 点击「删除」→ 确认后，该行从列表消失。 | 【截图：删除确认】 |
| **操作日志** | 点击「操作日志」→ 右侧抽屉查看历史记录。 | 【截图：操作日志抽屉】 |

本页**没有**导入、导出按钮，适合逐条维护。

#### 注意事项

- **同一产品下，产品形态名称不能重复**（不区分英文字母大小写，首尾空格不计入比较）；重复时无法保存。
- **参数类型只能选 Single 或 Multi**。
- **产品形态、参数类型、责任人均必填**。
- **删除后列表中不再显示该形态**；若以后用相同名称再新增，系统可能按规则恢复原有记录（以界面提示为准）。
- **形态编号由系统自动生成**，无需填写。
- 保存成功后，顶栏产品列表可能会刷新。

#### 2.2.1 命令（页签）

##### 页面简介

维护当前产品下的 **命令**（如各类 set 命令）及 **责任人**。参数管理左侧「命令树」、新增参数时的「归属命令」选项，都依赖这里的数据。

##### 使用指导

1. 顶栏选好产品后，打开 **命令** 页签。
2. 可在「按命令名称模糊查询」中输入关键字，点 **「查询」** 缩小列表。
3. 表格上方：**新增、刷新、导出、导入**；右侧 **「操作日志」**。

【截图：命令列表与查询区】

##### 功能操作

| 功能 | 操作步骤 | 截图位置 |
|------|----------|----------|
| **新增** | 「新增」→ 填写命令名称、责任人（多人用英文逗号分隔）→ 保存。 | 【截图：新增命令】 |
| **编辑** | 行内「编辑」→ 修改 → 保存。 | 【截图：编辑命令】 |
| **删除** | 「删除」→ 确认后从列表消失。 | — |
| **导入** | 「导入」→ 选 Excel 文件；可先点「下载模板」。**编号列为空表示新增，有编号表示修改。** | 【截图：命令导入对话框】 |
| **导出** | 「导出」→ 下载当前条件下的 Excel，**不含已删除记录**。 | — |
| **刷新** | 重新加载列表。 | — |
| **操作日志** | 查看命令相关历史操作。 | 【截图：命令操作日志】 |

##### 注意事项

- **同一产品下，命令名称不能重复**。
- **责任人必填**；多人请用**英文逗号**分隔。
- **命令编号由系统自动生成**，创建后请勿随意当作业务编码修改。
- **已删除的命令不会出现在列表和导出文件中**。
- 若新增的名称与曾经删除过的命令相同，系统可能直接恢复该命令并更新内容，而不是提示「名称已存在」。

#### 2.2.2 类型定义（页签）

##### 页面简介

为每个命令配置 **参数类型**（如 BIT、BYTE 等）及该类型允许的 **全局序号范围**（最小序号～最大序号），并填写类型名称、占用序号说明等。后续「版本区段」和「参数管理」中的序号、编码都与此相关。

##### 使用指导

1. 选好产品后进入 **类型定义** 页签。
2. 可按类型名称查询。
3. 列表显示：归属命令、类型名称、类型枚举、最小/最大序号、占用序号等。
4. 工具栏：**新增、刷新、导出、导入、操作日志**（用法同命令页签）。

【截图：类型定义列表】

##### 功能操作

| 功能 | 说明 |
|------|------|
| **新增** | 选择归属命令（须先在「命令」页签中建好）、填写类型名称、类型枚举、序号区间等 → 保存。**编辑时不能改归属命令。** |
| **导入/导出** | 与命令页相同；模板第一行会说明：「ID为空时新增，ID有值代表修改。」 |

【截图：新增类型定义表单】  
【截图：类型导入模板说明行】

##### 注意事项

- **同一产品、同一命令下，自定义类型名称不能重复**。
- **不同类型可以使用相同的序号区间**（例如 BIT 类型 0～100，BYTE 类型也可以配置 0～100）。
- **类型编号由系统自动生成**。
- 在 **版本区段** 中配置的序号范围，**不能超出**本页为该类型设置的最小～最大序号。
- 删除、导出规则与命令页一致。

---

#### 2.2.3 版本区段（页签）

##### 页面简介

在 **某一命令、某一参数类型** 下，按 **产品版本** 划分该版本实际能使用的 **序号区间**（例如某版本只能用 0～50）。录入参数时，系统会根据此处配置判断序号是否合法。

##### 使用指导

1. 选好产品后进入 **版本区段** 页签。
2. 可用顶部「按类型筛选」缩小范围，再点 **「查询」**。
3. 列表显示：归属命令、类型、所属版本、序号范围、说明、区段类型等。
4. 支持 **新增、刷新、导出、导入、操作日志**。

【截图：版本区段列表与类型筛选】

##### 功能操作

| 功能 | 说明 |
|------|------|
| **新增/编辑** | 选择命令、类型、版本，填写起止序号、区段类型、说明等。 |
| **导入/导出** | Excel 批量维护；导入结束会提示成功、失败条数。 |

【截图：新增版本区段】

##### 注意事项

- **区段的起止序号必须落在「类型定义」中为该类型配置的全局范围内**，否则无法保存。
- **同一产品、同一命令、同一类型、同一版本下，序号区段不能重叠**（例如版本 A 已占 0～50，版本 B 不能再占 0～50）。
- **区段编号由系统自动生成**。
- 已删除记录不出现在列表和导出中。

### 2.3 配置管理

**进入方式**：顶栏 → **配置管理**  

共 9 个页签，数据都按**当前顶栏所选产品**维护（**版本特性** 还需再选版本）。各页签界面类似：上方 **新增、刷新、导出、导入**，表格行内 **修改、删除**，多数页签有 **操作日志**。

【截图：配置管理页签栏】

#### 2.3.0 配置类页面：导入与导出（通用）

| 步骤 | 说明 |
|------|------|
| **下载模板** | 在导入窗口中点「下载模板」。模板第一行为说明：**「ID为空时新增，ID有值代表修改。」** 第二行为中文表头，与页面列一致。 |
| **导入** | 仅支持 **`.xlsx`**。选文件上传后，会提示成功、失败条数；**前面已成功的行不会因为后面某行失败而撤销**。 |
| **导出** | 下载 Excel，列与页面一致；**不包含已删除的数据**，也不包含系统内部用的状态、创建人等信息。 |
| **删除** | 点击「删除」后，该行从列表消失；页面上**没有单独的「启用/禁用」开关**。 |

【截图：配置类通用导入对话框】

**各配置页签通用注意事项**

- 数据只属于**当前选中的产品**。
- 列表中的 **编号（ID）由系统自动生成**，平时不用填写；导入时用编号区分新增还是修改。
- 若新增时使用的名称与曾经删除过的记录相同，系统可能**直接恢复**该条记录，而不是提示重复。

#### 2.3.3 变更来源关键字（页签）

##### 页面简介

配置 **变更来源** 的禁用规则：录入参数时若填写了「变更来源」，系统会用此处配置的正则表达式检查；**一旦匹配则不允许保存**（相当于黑名单）。

##### 使用指导

新增或修改时需填写：

- **正则**（必填）：正则表达式写法。
- **原因**（必填）：说明为何禁止此类表述。

列表主要展示「正则」一列。

【截图：变更来源关键字列表与表单】

##### 注意事项

- **正则表达式必须合法**，否则无法保存。
- **原因必填**。
- **只有当前有效的关键字**会参与参数保存时的校验。
- **关键字编号由系统自动生成**。

### 2.4 参数管理

**进入方式**：顶栏 → **参数管理**

#### 页面简介

在 **产品 + 版本** 下维护具体 **系统参数**，并填写 **变更说明**（为何修改、影响等）。支持按左侧「命令 → 类型」树筛选、表格分页、展开查看详情、**基线锁定**、批量导入导出。

#### 使用指导

**界面结构示意：**

```
┌─────────────────────────────────────────────────────────────┐
│  [版本：选某一版本，或 ALL（全产品）]                          │
├──────────────┬──────────────────────────────────────────────┤
│ 命令 / 类型树 │  新增 | 导入 | 导出 | 参数同步(暂不可用)        │
│              │  已基线数量 | 刷新 | 操作日志                   │
│              │  参数表格（可展开查看详情）                       │
└──────────────┴──────────────────────────────────────────────┘
```

**推荐填写顺序**

1. **基础标识**：先选归属命令 → 参数类型 → 点「可用序号」选序号 → 需要时「加载可选 BIT」并勾选 → 填参数名称（中）、取值范围等。  
2. **取值与场景**：按需填写说明、场景、默认/推荐值。  
3. **分类与归属**：从各下拉选网元、特性、分类等；手工填归属模块、变更来源、版本号。  
4. **长文本**与**扩展字段**：按文档要求补充含义、影响、举例等。  
5. **变更说明**：至少保留 **1 行**并填全必填列 → 最后点「保存」。

**导入模式说明**

| 模式 | 含义 |
|------|------|
| **全量导入** | 先清除当前版本、当前命令（及可选类型）范围内已有参数，再按文件全部导入。 |
| **增量导入** | 按参数编码新增或更新；**已基线的参数不会被改动**。 |

#### 注意事项

**版本与查看范围**

- **必须先选产品和版本**，否则列表不加载。
- **ALL（全产品）仅适合查询、看操作记录**，不能新增、导入；要做这些操作请切换到具体版本。
- **切换产品或版本后，左侧树筛选会重置**，请重新点选命令/类型。

**参数编码与序号**

- **参数编码由系统按「类型 + 序号」自动生成**（如 `BIT_8`），**无需也不应手工填写**。
- **序号须在「类型定义」和「版本区段」允许的范围内**；可点「可用序号」查看哪些序号完全可用、哪些部分可用。
- **同一版本、同一命令、同一类型、同一序号下，若有多条参数，各条占用的 BIT 位不能重复**；单条参数内 BIT 也不能重复勾选。

**BIT 与取值范围**

- 不同类型占用的 BIT 位数不同（如 BIT 为 1 位，BYTE 为 8 位，DWORD/STRING 常为 32 位）；**整数型等不需要 BIT 的类型不显示 BIT 区域**。
- **取值范围**为普通文本，格式不做强制校验，按业务约定填写即可。

**变更来源**

- **变更来源留空时不做关键字检查**。
- **填写后按您输入的内容原样保存**（系统不会自动去掉首尾空格）；若命中「变更来源关键字」中的规则，**无法保存**，提示中会显示匹配到的规则。

**变更说明**

- **每次保存至少填写 1 条变更说明**；原因、影响的中英文都要填。
- **新增参数时，变更类型只能选「新增参数」**；编辑时可选其它变更类型。
- **「是否导出」只能选「是」或「否」**；选「否」时必须填写 **不导出原因**。

**其它填写要求**

- **默认值、推荐值若填写，必须是整数**。
- **适用网元**从「配置管理 → 适用网元」多选，保存为顿号分隔的文字。
- **所属特性**来自当前产品、**该参数所属版本**下的版本特性。
- **是否立即生效**只能选 **「是」或「否」**。
- **生效方式英文**随中文自动填写，不能改。

**基线与导入导出**

- **基线后的参数不能编辑、删除**；增量导入也不会覆盖已基线参数。
- **解锁**后可再次修改（需确认）。
- 导入仅支持 **`.xlsx`**；导入结束会分别提示成功、失败条数，**已成功的行不会回滚**。
- 导出内容与列表可见列一致；模板中保留编号列是为了方便再次导入修改。
